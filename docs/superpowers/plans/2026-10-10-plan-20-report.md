## Global constraints
- **Number honesty.**
  - Paper numbers render only through `VerifiedNumber` or `Hole`.
  - System-computed numbers render only through `ComputedNumber`.
  - Counts use the display face with tabular figures.
  - Martian Mono (the verified face) is never used for unverified numbers: chart ticks, PRISMA counts and axes use the display face.
  - Prose must never show unverified paper numbers. Plan 19 strips untraceable numbers; the UI must not re-introduce any.
- **DESIGN.md Theatre Green.** Flat, with 2px corners, Okabe-Ito colours and glyph shapes that match the legend (◆ = harm only), 44px
  targets, Thai body text at 17px/1.75, and no page-level horizontal scroll at 390px.
- **Review types.** Legacy results render sensibly. Every type follows SECTIONS_BY_TYPE, which is extended rather than bypassed.
- **Offline.** The offline report works from `review.result` alone, with no network.
- **Localization.** The report UI chrome follows the report language: TH reports are all Thai, EN reports all English (nav, copy
  link, footer, offline header, aria labels).
- **Accessibility.** axe is clean in light and dark at 1440 and 390, every table has a caption and scope attributes, and every
  figure has a table twin.
- **Git.** Edit/Write only (LF). Stage only the files you touched. Commit messages end with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Gates.** frontend `npm test && npm run lint && npm run typecheck && npm run build:standalone && npm run e2e`; backend
  `uv run pytest -q && uv run ruff check .` when touched.

## Target section order (from the audit)
0. Title block: refined question as H1; "คำถามที่คุณพิมพ์"; metadata row (type, search date, n included, sources, language,
   review id); status block "อัตโนมัติ · อ่านเฉพาะบทคัดย่อ".
1. Bottom line: direct answer + certainty, or "รวมผลไม่ได้" for a meta-analysis with no pools.
2. Key findings: 3–5 bullets with verified or computed numbers.
3. Summary-of-findings table (SLR and meta-analysis): outcome, k, designs, participants, effect, certainty ⊕, plain statement.
4. Study selection: PRISMA 2020 / ScR flow with ruled boxes, plus excluded records with their reasons.
5. Study characteristics: design × year counts, compact literature matrix; the scoping evidence map goes here.
6. Results by outcome: per-outcome forest panel with a numeric column, favours labels and nice ticks; SR/MA in a separate block;
   the pooled block (k, I², τ², Q, prediction interval if available); a qualitative themes × studies table.
7. Risk of bias summary.
8. Consistency and conflicts.
9. Evidence landscape: concept map, citation network.
10. Limitations.
11. Research gaps.
12. Methods: eligibility, sources and date, queries, selection, extraction and verification, synthesis, certainty, models and
    prompt version.
13. References (Vancouver style, DOI/PMID/PMCID links, copy citation) and the excluded-at-screening disclosure.
14. Downloads and how to cite this report.

The source rail stays on the right, empty until the reader picks a study.
