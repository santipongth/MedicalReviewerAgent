# Plan 12: Optional 3D view of the live agent stage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an optional 3D view ("มุมมอง 3D") of the live-run agent stage, closer to the sakshigupta372/AI-Agent-observatory original: agent nodes as small 3D objects on a gently curved lane, curved tube edges, packets travelling along 3D arcs, a reader pool cluster, and a camera that drifts to the current agent. It is driven by the exact same real-time `Scene` (`src/lib/agent-scene.ts`) as the 2D stage — no new state, no fake progress. The 2D stage stays the default and the fallback.

**Architecture:**
- New deps: `three`, `@react-three/fiber@^9` (React 19), `@react-three/drei@^10` (only `Html`, `Line`/`QuadraticBezierLine` or equivalents actually used).
- `src/lib/agent-layout-3d.ts` (pure): 3D positions per visible agent (lane on a shallow arc in x/z, y=0), reader-pool cluster positions, and a 3D arc helper adapted from the observatory (`mid.y += |dx|*0.18 + 0.6`, quadratic through the lifted midpoint) with allocation-free `arc3X/Y/Z(seg,t)`.
- `src/components/review/stage3d/*`: `Stage3D` (Canvas root), `Node3D`, `Edge3D`, `Packets3D` (fixed pool, reuses `takeFreshPulses`/`planDots`), `ReaderPool3D` (instanced), `CameraRig`, `Labels3D` (drei `Html` DOM labels so Thai renders with the site fonts). Loaded only via `next/dynamic` (`ssr:false`) when the user turns the 3D view on, so nobody downloads three.js unless they ask for it.
- `StageView` wrapper in `live-run.tsx`: renders the 2D `AgentStage` by default; on wide screens (≥1024px, `useWide`) with WebGL available and reduced motion off, shows a toggle button "มุมมอง 3D" / "มุมมอง 2D". Preference stored in `localStorage` (wrapped in try/catch; failure → 2D).

**Tech Stack:** Next.js 16, React 19.2, three r18x, @react-three/fiber 9, @react-three/drei 10, Vitest + Testing Library, Playwright + axe.

**Spec:** The user's request of 2026-10-09 ("ทำไม ฉันไม่เห็น 3D") and choice "3D เป็นทางเลือก (แนะนำ)": an optional 3D view on wide screens, Theatre Green palette, same real events; mobile and reduced motion keep 2D. Plan 11 (`docs/superpowers/plans/2026-10-09-plan-11-agent-stage.md`) and DESIGN.md remain binding except the approved departures below.

## Global Constraints

- **Same truth as 2D.** Stage3D reads only `Scene` (and `layout-3d`). Every visual change traces to a scene change; no timer advances state; packets come only from `takeFreshPulses`/`planDots` with `seen` initialised at mount (bursts/replays collapse). Silent phases show only an indeterminate "working" look.
- **Approved DESIGN.md departures (3D view only):** depth and simple shading are allowed (one ambient + one directional light; `MeshStandardMaterial`/`MeshLambertMaterial` with flat colours). Still forbidden: bloom/glow/post-processing, starfields, particles, fog colour shifts, emissive "neon", gradients. Background = the `surface`/`ground` token colour. Status colours come from the same CSS tokens as 2D (read once from `getComputedStyle` on mount and on theme change), always paired with a shape cue (done = ring closed + check sprite or label ✓, failed = ✕ in label, uncertain = flag in label, working = rotating dashed ring).
- **Thai labels** are DOM (`Html` from drei, `pointer-events:none`, `font-display`, ≥12px), never canvas text.
- **Gating:** 3D toggle only when `useWide()` (≥1024px) AND WebGL available (pure `hasWebGL()` check, guarded) AND `prefers-reduced-motion` is not reduce. Otherwise the toggle is not rendered and 2D shows. If the Canvas fails (WebGL context lost/creation error), fall back to 2D with an error boundary.
- **Accessibility:** the 3D canvas wrapper is `role="img"` with the same `aria-label` as 2D (`sceneSummary`); canvas and labels `aria-hidden`; the toggle is a real `<button aria-pressed>`; the text ledger below is unchanged and remains the accessible source of truth. No keyboard trap (no OrbitControls focus capture; if orbit controls are used, they are pointer-only and do not capture keys).
- **Performance:** `frameloop="demand"` with `invalidate()` on scene change and during packet flights/camera moves; fixed packet pool (24) via one `InstancedMesh`; reader pool via one `InstancedMesh`; no per-frame allocations (preallocated vectors/matrices); DPR clamped to `[1, 2]`; dispose on unmount.
- **Bundle:** three/R3F/drei must live only in the lazily loaded 3D chunk — never in the eager `/r/[id]` JS, never in the 2D stage chunk, never in the offline report (`src/standalone`). Measure the lazy chunk and report it.
- **Numbers:** counts in labels use `font-display tabular-nums`, never `num-verified`/`VerifiedNumber`.
- **Attribution:** extend `NOTICE.md` to mention the 3D view adapts the observatory's node/arc/packet/camera ideas.
- **Git:** stage only touched files; Edit/Write tools only (LF; never Python text-mode writes); check `git diff --stat`; commits `feat(live3d): …`/`test(e2e): …`/`docs: …` ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Commands (frontend/):** `npm test`, `npm run lint`, `npm run typecheck`, `npm run build:standalone`, `npm run e2e`.

### Task 1: Dependencies + pure 3D layout

**Files:** `frontend/package.json` (+ lockfile), create `frontend/src/lib/agent-layout-3d.ts`, `frontend/src/lib/agent-layout-3d.test.ts`.

- Install `three`, `@react-three/fiber@^9`, `@react-three/drei@^10`, and `@types/three` (dev). Verify `npm ls react` shows a single React and peer ranges are satisfied.
- `layout3dFor(o: { showLocalize: boolean; showExternal: boolean; slots: number })` → `{ nodes: Partial<Record<AgentId, [number,number,number]>>; edges: { id: EdgeId; seg: Seg3 }[]; slots: [number,number,number][]; bounds: { min: Vec3; max: Vec3 } }`. Lane: visible PIPELINE agents spaced ~2.2 units along x, centred on 0, on a shallow arc in z (`z = -0.08 * x*x`), y = 0; external above read (y = 1.6); reader pool as a 6×5 grid on the y=−1.6 plane under read/synth, pitch 0.35.
- `arc3(a, b, bend=0.18)` → `Seg3 { a, c, b }` with lifted midpoint (`|b−a|·bend + 0.6` along +y), quadratic control `2·mid − (a+b)/2`; `arc3X/Y/Z(seg, t)` allocation-free.
- Edge ids must equal the 2D/scene vocabulary (reuse the logic/tests of `agent-layout.ts` `buildEdges`, including `synth>finish` when localize is skipped for non-Thai, and Thai-without-localizing behaviour) — add a test that every edge `reduceScene` can emit exists in `layout3dFor(...).edges` (copy the walk used in agent-layout.test.ts).
- Tests: midpoint lift, allocation-free helpers return numbers, nodes don't overlap (distance ≥ 1.2), slots count = min(n,30), bounds contain everything, edge vocabulary test.

### Task 2: Stage3D scene components

**Files:** create `frontend/src/components/review/stage3d/{stage-3d.tsx,node-3d.tsx,edge-3d.tsx,packets-3d.tsx,reader-pool-3d.tsx,camera-rig.tsx,labels-3d.tsx,tokens-3d.ts}` + tests where jsdom allows (pure helpers: token colour reader, status→visual mapping, packet assignment logic extracted as pure functions).

- `Stage3D({ scene })`: `<Canvas frameloop="demand" dpr={[1,2]} camera={{ position: [0, 4, 11], fov: 45 }} gl={{ antialias: true, powerPreference: "low-power" }}>` with background colour from tokens; one ambient + one directional light. Renders edges, nodes, reader pool, packets, labels, camera rig. Wrapper `<div role="img" aria-label={sceneSummary(scene)} className="aspect-[16/7] w-full max-w-[960px] rounded-sm border border-rule">`; canvas `aria-hidden`.
- `Node3D`: core (small icosahedron, flat-shaded) + ring (torus); status → colour token and ring style: idle `rule`, active `primary` scale 1.12, working `primary` + ring rotation (only while working; `invalidate` each frame only while any node is working or a packet is in flight), done `ink`, failed `err`, skipped `muted` with wireframe ring, paused `warn`. No emissive glow.
- `Edge3D`: tube or `Line` along the arc; idle `rule`, visited `ink`, live `primary`.
- `Packets3D`: one `InstancedMesh` of 24 small spheres; on `scene.lastSeq` change compute fresh dots with `takeFreshPulses(scene.pulses, seen, PACKET_CAP)` + `planDots(…, MAX_DOTS)`; animate t over 700ms with `delayMs` in `useFrame` using preallocated objects; hide finished instances (scale 0); `seen` initialised at mount. Pure assignment/scheduling helper extracted and unit-tested.
- `ReaderPool3D`: one `InstancedMesh` of up to 30 spheres coloured by slot state (waiting `rule`, reading `primary`, ok `ok`, failed `err`, uncertain `warn`).
- `Labels3D`: drei `Html` per visible node with `AGENT_LABEL` Thai lines + count (tabular-nums), and P-ref/✓/✕/flag markers only for the pool summary (not 30 labels); `pointer-events:none`; `font-display` ≥12px.
- `CameraRig`: eases the camera target toward `currentAgent(scene)` (lerp per frame while moving; `invalidate` until settled). Under reduced motion this view is never shown (gated), but still guard: jump instead of lerp if `matchMedia` reduce.
- `tokens-3d.ts`: read CSS custom properties (`--primary`, `--ink`, `--rule`, `--muted`, `--ok`, `--err`, `--warn`, `--surface`) once on mount and on theme change (observe `data-theme`/`prefers-color-scheme`), returning hex strings; pure parser unit-tested.
- Dispose geometries/materials on unmount (R3F does most; verify custom ones).
